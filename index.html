Projects

I started learning to code through the Le Wagon web development programme, and this is my first project.

Personal profile page

2025 · Le Wagon challenge

  • HTML
  • CSS
  • Responsive design
  • Google Fonts
  • Font Awesome

This is the page you're looking at right now. It was built as part of the Le Wagon HTML & CSS challenge, where the goal was to create a personal profile from scratch. I went beyond the basics and added multiple sections, responsive layouts, photo collages, a reading progress bar, scroll animations, and published it on GitHub Pages.

What I learned

  • Structuring a page with semantic HTML: sections, figures, navigation, and headings
  • Responsive CSS using grids, flexbox, clamp(), and media queries
  • Working with external assets: Google Fonts, Font Awesome icons, and SVG logos
  • Publishing a website with Git and GitHub Pages
